# 素材列表与逐项分析规范

适用于所有包含“上传多个素材 → AI 分析 → 展示结果”的产品页面。目标：素材列表不占满页面，模型一次只处理一项，结果可追溯，进度始终可见。

## 1. 素材列表

- 列表只显示固定尺寸缩略图（建议 64–96 px），不内联大图、长描述或可编辑表单。
- 缩略图显示序号和逐项状态：待分析、分析中、已完成、失败；失败使用红色边框和错误图标。
- 点击缩略图打开预览：大图 + 该项的标题、AI 分析结果、标签、用户备注、完成时间和删除入口。
- 删除按钮放在缩略图悬停层或预览内，不挤占缩略图主体；触屏和键盘焦点下必须可见。
- 批次、分组等容器信息保留在列表上方，不重复到每张缩略图下。

## 2. AI 分析粒度

- 一次模型调用只处理一个素材：多张图片不得拼进同一条请求。
- 每一项独立落库：状态、任务 ID、错误、原始结果、结构化描述/标签、完成时间。不要只把汇总结果写回项目。
- 默认按后台配置的并行数执行（批量视频默认同时 10 张，可在后台调整 1–50）；一次调用仍只处理一个素材，并发数用于控制费用和渠道压力。
- 单项失败时停止补位并等待用户确认继续或中止；已在途项继续跑完并落库，全部结束后再汇总项目级摘要、卖点和合规提示，并报告失败数量。
- 再次分析默认只处理尚未成功分析的项（待分析、失败、已中止）；只有显式“重新分析全部”才重跑已完成项，确认文案必须写明覆盖范围。

## 3. 前台进度

- 用户主动发起的分析必须在前台显示逐项进度，不提供“后台运行”入口。
- 进度窗展示：总项数、已完成/失败数、当前并行数量与运行项、每项缩略图状态、已运行时间。
- 运行中不可关闭：不显示关闭按钮，禁用遮罩点击和 Esc；只提供“中止分析”。
- 离开页面不丢任务，返回项目或刷新后自动重新打开进度窗，直到完成或中止。
- 中止后保留已完成结果和素材；当前项标记中止，剩余项回到待分析。

## 4. 服务端与状态

- 服务端队列负责实际执行；前台进度只是对持久状态的投影，不能把长任务绑在浏览器请求上。
- 项目级状态只表达整体：`queued/running/awaiting_decision/succeeded/failed/cancelled/stale`；单项状态挂在素材/资产记录上。
- 汇总档案在一个分析轮次结束时只递增一次版本，避免每张图片都生成新版本。
- 删除、清空、重新分析等写路径沿用现有权限、归属和“运行中拒绝修改”校验。

## 5. 落地检查清单

- [ ] 列表只显示缩略图，点击可预览大图和该项结果。
- [ ] 每次模型请求只包含一个素材。
- [ ] 每项结果独立持久化，失败项可定位。
- [ ] 进度窗在前台且运行中不可关闭。
- [ ] 中止和失败不丢已完成结果。
- [x] 再次分析默认只补跑未完成项，“重新分析全部”在确认文案中写明覆盖范围。
- [ ] 文档同步 API、数据表、功能和待测试记录。
